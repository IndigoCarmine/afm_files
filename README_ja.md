# Kintuba AFM Viewer

Bruker Nanoscope の SPM ファイル（`.spm`）を表示・解析するデスクトップアプリケーションです。Pure Rust + [egui](https://github.com/emilk/egui) で実装されています。

アプリの UI は英語です。以下の説明でボタン名を引用している箇所は、画面上の表記をそのまま示しています。

## 機能

- **ファイルブラウザ** — フォルダを開いて Nanoscope SPM ファイル（`.spm`、`.000`〜`.009` など）を一覧表示
  - `_` 区切りを意識したワイルドカードで絞り込み（[ファイル名フィルタ](#ファイル名フィルタ)）
  - ファイルをダブルクリックするとファイル名をクリップボードにコピー
- **高さマップ表示** — AFM の高さチャンネルをカラー画像として描画
  - カラーマップ: AFM Hot / Gray / Viridis
  - Z 範囲コントロール（ドラッグで入力、データの最小・最大値を超えた設定も可能）
  - **Data Range** ボタンで元の Min/Max にリセット
- **多項式ラインフラットニング** — 0〜3 次、デフォルトは 2 次
- **機器ごとの XYZ 校正** — 装置固有の縦横比の歪みと高さ誤差を自動補正（[機器ごとの XYZ 校正](#機器ごとの-xyz-校正)）
- **パン・ズーム** — スクロールでズーム、ドラッグで移動、リセットボタンあり
- **解析タブ**
  - 画像上の 2 点をクリックしてライン断面を描画
  - 緑（始点）・赤（終点）のハンドルをドラッグして調整
  - 断面プロット（横軸: 距離 nm、縦軸: 高さ nm）
  - **マーカー A/B** — プロット上をクリックしてマーカーを 2 点設置、ΔD（距離差）と ΔH（高低差）を表示
  - プロット右クリックでマーカーをクリア
  - 断面データを CSV または PNG でエクスポート

## 対応ファイル形式

| 形式 | 説明 |
|------|------|
| `.spm` | Bruker Nanoscope SPM（標準拡張子） |
| `.000`〜`.009`、`.00000` 等 | 数字拡張子の Nanoscope ファイル |

パーサーはテキストヘッダーを `\*File list end` まで読み込み、Height チャンネル（Retrace 優先）を選択します。ヘッダーに埋め込まれた感度キャリブレーション値を使って生の LSB 値をナノメートルに変換し、必要に応じてライン単位の多項式フラットニングを適用します。

## ビルドと実行

```sh
cargo run
```

Rust 2021 エディション以降が必要です。

### 依存クレート

| クレート | 用途 |
|---------|------|
| `eframe` / `egui` | ネイティブ GUI フレームワーク |
| `egui_plot` | 断面プロットウィジェット |
| `rfd` | ネイティブファイルダイアログ |
| `image` | PNG エクスポート |

## 使い方

1. **Open Folder** をクリックして SPM ファイルが入ったフォルダを選択する。
2. 左パネルのファイルをクリックして読み込む。
3. カラーマップ・フラットニング次数・Z 範囲を必要に応じて調整する。
4. **Analysis** タブに切り替えてライン断面を描画する。
5. 断面プロット上をクリックしてマーカー A・B を設定すると、ΔD と ΔH がプロット下に表示される。
6. **Save CSV** または **Save PNG** で断面データをエクスポートする。

### 機器ごとの XYZ 校正

AFM 本体の校正は完全ではなく、残った誤差は装置固有のものとして現れます。横方向は
縦横比の歪みとして、Z 方向は高さが一律に高め／低めに出る形で効いてきます。
ツールバーの **⚙ Calibration** を開くと、ファイルヘッダの `\Serial Number`（例 `10396jvlr`）
をキーにした X/Y/Z 拡大率のテーブルを編集できます。登録済みの機器で測定した
ファイルを開くと、倍率が自動的に適用されます。

- **X / Y** は走査寸法に掛かり、画面上のアスペクト比・スケールバー・
  ライン断面の距離・3D 表示を補正します。
- **Z** は高さデータそのものに掛かり、Z 範囲・断面の高さ・ΔH 表示・
  断面 CSV の出力がすべて補正後のナノメートルになります。

Z は高さデータと表示レンジの両方に同じ倍率が掛かるため、Z 倍率によって画像の
見た目が変わることはありません（変わるのは数値だけです）。

**保存・コピーする画像は Raw（未補正）のまま**です。測定値を収めるファイルに
補間したピクセルを混ぜないためで、ピクセル格子が実寸比と一致しない場合は
保存・コピーのボタン横と実行後の両方に警告を出し、実寸比にするために必要な
倍率（例 `scale height ×1.0230 for the true aspect`）を併記します。焼き込む
スケールバーは画像の横幅を基準に計算しているため、どちらの場合も正しい長さに
なります。

倍率が黙って掛かった画像は生データと見分けがつかないため、**1.0 以外の倍率が
適用されている間は画像の枠が赤くなり**、適用中の倍率が併記されます。

テーブルは手で編集できるテキストファイルとして保存されます。

| OS | パス |
|---|---|
| Windows | `%APPDATA%\KintubaAfmViewer\calibration.txt` |
| macOS | `~/Library/Application Support/KintubaAfmViewer/calibration.txt` |
| Linux | `$XDG_CONFIG_HOME/kintuba-afm-viewer/calibration.txt`（無ければ `~/.config/…`） |

```
# Kintuba AFM Viewer — instrument XYZ calibration
# <serial number>  <x scale>  <y scale>  <z scale>
10396jvlr  1.000000  1.023000  0.987000
```

空行と `#` 行は無視され、`z` 列は省略可能です（省略時は 1.0）。書式の壊れた行は
起動を止めずに読み飛ばし、どの行を飛ばしたかをダイアログに表示します。ファイルが
無い場合は未校正、つまり全機器 ×1.0 として動作します。

### ファイル名フィルタ

ファイルリスト上部の入力欄で一覧を絞り込めます。マッチ対象は拡張子まで含めた
ファイル名全体で、英大文字・小文字は区別しません。

| パターン | 意味 |
|---------|------|
| `*` | `_` をまたがない任意の文字列 |
| `**` | `_` を含む任意の文字列 |
| `{<20260808}` | その位置の数字列に対する数値比較（`<` `<=` `>` `>=` `=` `!=`） |
| `{>=20260101,<20260808}` | カンマ区切りは AND 条件 |
| `{EtOH|MeOH}` | 列挙したいずれかに一致 |

`*` も `{` も含まない入力は単純な部分一致検索になるので、`EtOH` と打つだけでも
絞り込めます。

```
{<20260808}_*_*_*_EtOH10_**
```

は「2026-08-08 より前の日付 + 任意の 3 セグメント + `EtOH10` + 任意」を表し、
`20260101_sampleA_p1_run3_EtOH10_scan.003` にマッチします。
